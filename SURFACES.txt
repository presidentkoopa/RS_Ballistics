// ============================================================================
// SURFACES -- what textures are made of, read by the engine (#16, engine
// 463098530b). TexMan.GetSurface(tex) answers; RSB_Materials asks it on every
// landing, and the answer picks impact variants (bullet.metal, rocket.wood...).
//
// Converted from RS_Ballistics' old RSBDEFS `material` blocks, pattern for
// pattern (0 mismatches over Doom 2's 575 textures).
//   - In a pattern, * matches any run and ? one character. Quote patterns.
//   - walls = wall textures, flats = flats, any = every texture type. The engine
//     keys on the texture's own type, so a flat on a UDMF wall answers its flat
//     rule.
//   - A later rule or lump wins, so a map pack's SURFACES can reclassify;
//     `surface none` un-tags.
//   - A new surface name needs no code: give it `.name` impact variants in
//     RSBDEFS.
// ============================================================================

// LAVA IS NOT A LIQUID, whatever the flat list used to say. A round into molten rock does not
// splash and does not leave the surface WET: it throws lumps that arc, glow and cool, it spits,
// it lifts embers and it burns the air above it. It is listed after `liquid` on purpose -- a later
// surface takes its textures back -- and it takes the lava falls with it, which were falling
// through to no surface at all before.
surface lava
{
	walls = "FIRELAV*", "FIREMAG*"
	flats = "LAVA*"
}
