// ============================================================================
// RS_Ballistics particle definitions -- GPU particles stage 2 (PARTICLEDEFS).
//
// PACKED since engine dece74eb8d (stage 2b). An RSBDEFS burst uses one with
// `particle = <name>` (RSB_Burst -> level.SpawnParticles, by handle).
//
// ALL IN USE since engine 6997b2c308 (stage 2d: lit, alpha-blended, soft):
//   rsb_flame_puff, rsb_flame_tip   the flamethrower's body and tip (burst particle),
//                                   and flame_sheet where it lands
//   rsb_smoke_gun                   muzzle smoke (flash `smokeparticle`), rsb_bench_smoke200
//   rsb_smoke_flame                 black smoke where a flame lands (burst flame_smoke)
//   rsb_dust_concrete, rsb_dust_wood  impact dust (bursts dust_concrete, dust_wood)
// LIGHT: sector light at spawn, plus up to 32 dynamic lights in view. A muzzle
// flash's strobe is one (A_AttachLight), so it colours nearby smoke.
// NOT SORTED: a newer puff dims an older spark in front of it, and so on.
// SOFT: a definition's own `soft` wins over the Soft particles slider.
// TINT colours the smoke body; intensity scales only emissive.
// SIZE CAP: min(maxsize, r_gpuparticles_maxsize). The cvar defaults to 8, so the
// bigger sizes here show once it is raised (the engine's size-cap slider, F5).
// COLLIDE (engine F4, built in 2b): `collide = plane` keeps particles in front of
// the surface an emission names and skids them on the floor in front of it.
// RS_Ballistics names one where a round lands (RSB_Impact.LandOn) and where a
// flame lands (its stream and landing bursts). An emission with no surface -- a
// muzzle, a blast in mid-air -- names none, and the key changes nothing.
// Engine notes: Engine docs/STAGE2B_IMPL_NOTES.md, STAGE2C_IMPL_NOTES.md,
// STAGE2D_IMPL_NOTES.md.
//
// WHAT GOES HERE: only what inline bursts cannot do. Sparks, chips and glints
// work as they are (SpawnGpuParticles draws through inline definitions). These
// need the new keys:
//   - size ramps past the old 8-unit cap (flame puffs, dust clouds)   2b
//   - staying in front of a surface, sliding along it                   2b
//   - alpha that hides what is behind it                               2d
//   - light from the lights in view (a muzzle flash turns smoke orange) 2d
//   - soft contact with walls and floors                               2a
//   - animated smoke frames                                            2c
//
// Keys (value @ life fraction for ramps, up to 8 keys):
//   size, color, alpha, emissive   ramps
//   lit 0..1   gravity   drag   maxsize   soft (map units)
//   texture = "<first frame>", frames, fps, loop | once
//       A SPRITE frame name steps its frame letter, keeping the rotation digit:
//       "RSSKA0", 6 is RSSKA0, RSSKB0 ... RSSKF0. Any other name counts its
//       trailing number up, padding kept (SMOKE01 ... SMOKE06). A missing frame
//       refuses that one definition. Approved; GPU_PARTICLES_STAGE2_PLAN.md 2c.
//   orient = billboard | streak | flake   stretch   spin = min, max
//   collide = none | plane
// ============================================================================

// ---------------------------------------------------------------- FLAME
// The flamethrower's body: small and white-hot out of the nozzle, swelling to
// big orange puffs, cooling to dark red. Additive (alpha 0 throughout).

{
	size     = 3 @0, 16 @0.4, 30 @1
	color    = 255 240 200 @0, 255 150 45 @0.35, 170 50 15 @1
	alpha    = 0 @0, 0 @1
	emissive = 3.5 @0, 2.2 @0.5, 0 @1
	lit      = 0
	gravity  = -60
	drag     = 0.4
	maxsize  = 48
	soft     = 8
	orient   = billboard
	spin     = -120, 120
	collide  = plane
}
