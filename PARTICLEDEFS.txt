// ============================================================================
// RS_Ballistics particle definitions -- GPU particles stage 2 (PARTICLEDEFS).
//
// An RSBDEFS burst uses one with `particle = <name>` (RSB_Burst ->
// level.SpawnParticles, by handle). A burst's `color` tints the definition (the
// definition's colour ramp multiplies it), so one neutral piece of debris serves
// every material.
//
// THE RULES (owner, 2026-09-14): grounded combat -- the Matrix lobby, F.E.A.R.,
// Trepang2, Max Payne, Selaco. STRICT colour: dust, smoke and debris give no light
// of their own (lit 1, emissive 0) and are seen where muzzle flashes, sparks, fire
// and the room's lights reach them. Only hot things (fire, sparks) and Doom's energy
// weapons glow.
//
// SPRITES: sprites/ -- RSSK (smoke), and from tools/import_fx.py (ASSETS.md):
//   RSDS dust roll, RSFB fireball, RSFK flame lick, RSSO soot puff, RSSP spark
//   spray, RSEC electric arc (copied from RS_Main's combat effects, owner-cleared);
//   RSCH chips, RSSL splinters, RSCL clods, RSGS glass shards (generated).
// DEBRIS cycles through its four shapes as it spins, so a tumbling piece changes
// silhouette like a real one turning.
//
// LIGHT: sector light at spawn, plus up to 32 dynamic lights in view.
// NOT SORTED: a newer puff dims an older spark in front of it, and so on.
// SOFT: a definition's own `soft` wins over the Soft particles slider.
// SIZE CAP: min(maxsize, r_gpuparticles_maxsize); raised to 64 by Ballistics &
// Effects -> "All effects on".
// COLLIDE: `collide = plane` keeps particles in front of the surface an emission
// names and skids them on the floor in front of it.
// NEXT: dust and fire move to generated looks (Engine docs/GPU_PARTICLE_LOOKS_PLAN.md,
// staged in _staged/PARTICLEDEFS_looksA.txt) when that engine build lands.
//
// Keys (value @ life fraction for ramps, up to 8 keys):
//   size, color, alpha, emissive   ramps
//   lit 0..1   gravity   drag   maxsize   soft (map units)
//   texture = "<first frame>", frames, fps, loop | once
//   orient = billboard | streak | flake   stretch   spin = min, max
//   collide = none | plane
// ============================================================================
