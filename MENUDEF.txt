// ============================================================================
// RS_Ballistics menu: Options -> "Ballistics & Effects". Every rsb_ control here
// is checked by tools/menu_lint.py on each build against CVARINFO and the code: a
// control for a cvar nothing reads fails the build.
//
// THE OWNER'S RULE (2026-09-14): our effects are ON by default, at good quality,
// and there are lots of them. The page groups every effect, the engine's
// renderer-read effect cvars included (they respond while the menu is open), and
// its first row sets them all to their recommended values (KEYCONF
// rsb_all_effects_on), because a changed default never reaches a saved ini.
//
// Settings apply to the next shot, impact or casing. Preview rows fire a test
// effect through a netevent; close the menu (or keep the world visible) to see
// it.
// ============================================================================
