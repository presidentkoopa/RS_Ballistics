// ============================================================================
// VOLUMEDEFS -- RS_Ballistics' emissive volumes (engine #15): muzzle flashes and blasts as real glowing gas with
// depth in the headset. A flash or impact profile names them with `volume` (RSBDEFS); where one draws, the flat flame
// card and the lit-air cone stand down, and the sparks, smoke, shimmer and the strobe (with its wall shadows) stay.
//
// CLASS is told honestly, so the player's "Volumetric flashes" setting (All / Big guns and blasts / Explosions only /
// Off) keeps its meaning: gun = pistols, SMGs, rifles, chainguns; biggun = shotguns, launchers, plasma, rail, BFG at
// the muzzle; blast = where something explodes. Sized for the look (owner, 2026-09-15: "we will do an optimize pass
// later"). Each light lights the smoke and particles; the strobe lights the walls.
// The effects level scales every spawn (RSB_Tier.SizeScale, GlowScale): plain smaller and dimmer, extreme bigger.
// ============================================================================
