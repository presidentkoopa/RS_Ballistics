// ============================================================================

// voxels/MISLA.kvx; tools/import_rocket_voxel.py), drawn as a model so it flies nose first
// (USEACTORPITCH) and spins (USEACTORROLL) -- RSB_Rocket sets both each tic. Only the
// flight frame (MISL A); the blast frames stay Doom's sprites. A voxel drawn as a model is
// coloured through its palette skin (rocket_pal.png), which MODELDEF must name.
// AngleOffset 270: this voxel set faces right (as RS_Main's and RS_VRBody's).
// ============================================================================

// ============================================================================
// THE ROUND IN FLIGHT (zscript/rsb/bullet.zs; roundlook `look = model, RSBM<frame>`).
//
// models/bullet/btracer.obj, out of E:/oldshit/outdatedHFmaster/Models/btracer -- the owner's
// own older tree, and the bullet they have been watching fly. It is one hexagonal tube, 80
// units long and 7 across, centred on the origin.
//
// EIGHT SIZES OF ONE MESH. A round's calibre is a LOOK, not a second model: each block below
// is the same tube at its own length and girth, bound to its own frame of the RSBM sprite.
// A mod that wants a ninth adds a block and names its frame -- no ZScript, no new asset.
//
// RSBM itself is a 1x1 transparent lump. GZDoom has to hang a model on a sprite frame and
// TNT1 is special-cased out of drawing, so the sprite is a mount point that draws nothing.
// There is no bullet sprite in this package and there is not going to be one.
//
// DontCullBackfaces: the tube is thin enough to see the inside of at a grazing angle.
// USEACTORPITCH / USEACTORROLL: bullet.zs turns the actor to face its own velocity each tic,
// so the streak lies along the flight instead of wherever the gun was pointing at spawn.
// ============================================================================

Model RSB_Bullet   // pistol -- a 9mm, .45 or .38 in flight: a short thin dart
{
	Path "models/bullet"
	Model 0 "btracer.obj"
	SurfaceSkin 0 0 "btracer.png"
	Scale 0.2500 0.2286 0.2286
	DontCullBackfaces
	USEACTORPITCH
	USEACTORROLL
	FrameIndex RSBM A 0 0
}
